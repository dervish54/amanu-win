## Выполнено

- **Деинсталлятор: гранулярный выбор.** Вопрос о данных перенесён после
  удаления файлов (`CurUninstallStepChanged(usPostUninstall)`), форма с
  чекбоксами: модели распознавания / данные Ollama / записи и расшифровки /
  настройки. По умолчанию всё снято; silent-деинсталляция ничего не спрашивает
  и не удаляет. Пути читаются из реального config.json.
- **Ollama Welcome.** `close_ollama_welcome()` закрывает окно после шага
  установки Ollama (WM_CLOSE по заголовку окна).
- **Обратная связь о завершении.** First-run больше не исчезает сам: финальный
  экран «Готово! Amanu работает в трее. Ctrl+Alt+R — запись…» с кнопкой
  «Начать пользоваться» остаётся до действия пользователя.
