# Backlog

## Деинсталлятор: гранулярный выбор что удалять

Живой тест 2026-09-19 показал два дефекта UX:
1. Вопрос про данные идёт ПЕРЕД штатным подтверждением Inno — два разрозненных
   окна, нелогичный порядок. Перенести вопрос о данных в
   `CurUninstallStepChanged(usPostUninstall)`: стандартное подтверждение →
   удаление программы → одно окно про данные.
2. «и все компоненты программы» (сток Inno) путает — неясно, что за компоненты.

Нужно окно с отдельными чекбоксами:
- [ ] скачанные модели распознавания (`models_dir`)
- [ ] Ollama и модель сводок (ставится через winget, живёт в `%USERPROFILE%\.ollama`)
- [ ] записи и расшифровки (`recordings_dir`)
- [ ] конфиг (`~/.config/amanu/config.json`)

По умолчанию всё снято (ничего не удалять). Silent-деинсталляция не спрашивает
и ничего не удаляет (уже сделано). Реализация: `CreateCustomForm` из
`CurUninstallStepChanged` — InitializeUninstall рисует только до удаления.
