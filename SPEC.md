# Спецификация amanu-win

Требования продукта и сверка с тестовым покрытием. Требования собраны из
пользовательских промптов и README; статус — по фактическому наличию тестов
и живых проверок на 2026-09-18.

## Функциональные требования

| # | Требование | Критерий приёмки | Покрытие | Статус |

| F2 | Захват того же микрофона, что слышат обычные приложения (браузер, мессенджеры) + loopback системного звука | если Chrome слышит микрофон — Amanu слышит | `test_mic_selection` (3: регрессия инцидента 1905 с расходящимися дефолтами, fallback-ы) + живая проверка endpoint | ✅ покрыто (исправлено 2026-09-18) |
| F3 | Два раздельных канала (mic=left, system=right); время файла = стенному ±5–15% | 6 с записи → ~6 с файла | `test_recorder_timing` (2), полный цикл через exe | ✅ покрыто |
| F4 | Стриминг микрофона вживую: чанки 0–10 с, шаг 8 с, пересечение 2 с | фрагменты появляются во время записи | `test_chunking` (6: расписание, эмиссия, хвост, инцидентные регрессии); живой прогон ChunkTap→whisper | ⚠️ юниты да; связка recorder→tap вживую проверялась вручную |
| F5 | LLM-сшивка фрагментов: дубли убраны, пунктуация восстановлена; fallback — наивная склейка | «fellow americans» ровно 1 раз | `test_stitch` (6) + E2E с реальным qwen | ✅ покрыто |

## Нефункциональные требования

| # | Требование | Покрытие | Статус |
|---|---|---|---|

| N2 | Хоткей и меню отвечают <0.5 с при любой нагрузке | `test_async_toggle` (2), `test_hotkey_stop::test_stop_returns_fast…` | ✅ покрыто (меню — по тому же каналу маршаллинга) |

| N4 | Локальность данных; `--setup` идемпотентен; модели не в репо | `test_setup` (9), `test_config_defaults` (3) | ✅ покрыто |
| N5 | GPU-транскрипция; запись не ждёт модель | по конструкции (отдельные потоки), замеров нет | ⚠️ по конструкции |
| N6 | Обработка минуты записи < минуты; буфер O(n) | замеров нет | ⚠️ не измерено |

## Итог сверки

- **Покрыто тестами/проверками:** F1, F3, F5, F6, N2, N3, N4 — 7 из 15.
- **Частично:** F4 (связка с рекордером), F7 (интеграция), F8 (нет юнита), F9 (цвета), N5, N6 — 6.
- **Провалено:** **F2, N1** — выбор и надёжность микрофонного устройства. Именно этот класс дал инцидент 1905. Приоритет №1.

## План закрытия провалов (в порядке приоритета)

1. **F2/N1 — устройство захвата.** Открывать тот же endpoint, что берут обычные приложения (Default Communications / совпадение по имени с системным default input), логировать фактически открытый endpoint (имя + rate), realtime-вотчдог: <0.5 с кадров за первые 5 с записи → предупреждение сразу, а не post-mortem. Приёмочный сценарий: «диктую 30 с, параллельно браузер слышит тот же микрофон».
2. **F8** — юнит на `summarize` (промпт/секции, обработка недоступности Ollama).
3. **F4** — интеграционный тест recorder→tap→fragments на живых устройствах (отмечен как hardware-dependent).
4. **F9** — цвет/заголовок иконки по состояниям (юнит на `_refresh` через фейковый icon).

Требования, помеченные «по конструкции», получают тест только при появлении
правдоподобного бага, который бы они поймали (см. политику тестов в README).
